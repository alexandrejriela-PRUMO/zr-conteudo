# zr-conteudo

Artes publicadas nas redes do Zubiaurre & Riela Advogados Associados (@zr.adv) e o que a tarefa agendada usa para gerá-las.

- `INSTRUCOES.md`: regras da OAB para a publicidade, público, tom, pilares, e como os posts são gerados, aprovados e publicados.
- `historico.md`: lista dos posts já publicados.
- `sistema/`: modelo das artes (render.py), logo do escritório e fontes (EB Garamond e Lato, licença OFL em `sistema/fontes/`).
- `posts/`: uma pasta por post (post.json + imagens).

Conteúdo de caráter informativo. Este repositório é público porque o Instagram precisa buscar as imagens por link aberto.
Não coloque aqui nada que não vá ser publicado: nenhuma peça, documento ou dado de cliente.
